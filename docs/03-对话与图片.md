# 对话与图片

## 普通对话

```java
PiRun run = client.prompt("修复失败的单元测试");
run.accepted().join();
run.settled().join();
```

同一个客户端有普通运行未结束时，再调用 `prompt()` 会抛出 `IllegalStateException`。运行中修改方向使用 `steer()`，排队到运行结束后处理使用 `followUp()`。

```java
client.steer("先只定位根因，不修改文件").join();
client.followUp("最后给出变更摘要").join();
client.clearQueue().thenAccept(queue -> {
    System.out.println(queue.steering());
    System.out.println(queue.followUp());
});
```

## 流式期间发送 prompt

需要由调用方明确选择行为：

```java
client.prompt("补充要求", List.of(), PiStreamingBehavior.STEER);
client.prompt("下一项任务", List.of(), PiStreamingBehavior.FOLLOW_UP);
```

普通 `prompt()` 的单运行保护仍然存在。优先直接调用 `steer()` 或 `followUp()`，语义更清楚。

## 图片

```java
PiImage image = PiImage.fromPath(Path.of("screen.png"), "image/png");
PiRun run = client.prompt("指出截图中的错误", List.of(image));
run.settled().join();
```

`PiImage` 保存 Base64 数据和 MIME 类型。发送前应限制文件大小，只允许业务认可的图片类型。

## 中止

```java
client.abort().join();
```

中止命令成功表示 PI 接收了中止请求。运行是否完全稳定仍以 `agent_settled` 为准。
