# 对话与图片

## 普通对话

```java
PiRun run = client.prompt("修复失败的单元测试");
run.accepted().join();
run.settled().join();
```

`PiRun` 是 `record (CompletableFuture<PiResponse> accepted, CompletableFuture<PiEvent> settled)`，两阶段语义：

| 阶段 | future | 完成时机 | 含义 |
| --- | --- | --- | --- |
| 接收 | `accepted()` | prompt preflight 成功 | PI 已接受或排队该 prompt |
| 稳定 | `settled()` | 收到 `agent_settled` 事件 | 自动重试、压缩和后续队列均已结束 |

**不要用 `accepted()` 判断模型回答完成**，完整运行结束必须等待 `settled()`。若 prompt 在 preflight 阶段被拒绝（例如运行中未指定 `streamingBehavior`），`accepted()` 会异常完成。

同一个客户端有普通运行未 `settled()` 时，再调用 `prompt()` 会抛出 `IllegalStateException`。运行中修改方向用 `steer()`，排队到运行结束后处理用 `followUp()`：

```java
client.steer("先只定位根因，不修改文件").join();
client.followUp("最后给出变更摘要").join();
client.clearQueue().thenAccept(queue -> {
    System.out.println(queue.steering());
    System.out.println(queue.followUp());
});
```

## 流式期间发送 prompt

需要由调用方明确选择行为：

```java
client.prompt("补充要求", List.of(), PiStreamingBehavior.STEER);
client.prompt("下一项任务", PiStreamingBehavior.FOLLOW_UP);
```

- `STEER`：当前 assistant turn 的工具调用结束后插入。
- `FOLLOW_UP`：当前 Agent 完全停止后再处理。

普通 `prompt()` 的单运行保护仍然存在。优先直接调用 `steer()` 或 `followUp()`，语义更清楚。

## 图片

```java
PiImage image = PiImage.fromPath(Path.of("screen.png"), "image/png");
PiRun run = client.prompt("指出截图中的错误", List.of(image));
run.settled().join();
```

`PiImage` 是 `record (String data, String mimeType)`：

- `data` 为**不带 Data URL 前缀**的 Base64 数据。
- `mimeType` 必填且不能为空白。
- `PiImage.fromBytes(byte[], mimeType)` 从字节数组编码。
- `PiImage.fromPath(path, mimeType)` 读取文件并编码，抛 `IOException`。

发送到 PI 的图片在线格式为 `{"type":"image","data":...,"mimeType":...}` 数组。发送前应限制文件大小，只允许业务认可的图片类型。

图片也可用于 `steer` 和 `followUp`：

```java
client.steer("对照这张图检查", List.of(image)).join();
client.followUp("补充图中问题", List.of(image)).join();
```

## 中止

```java
client.abort().join();
```

中止命令成功表示 PI 接收了中止请求。运行是否完全稳定仍以 `agent_settled` 事件为准。
