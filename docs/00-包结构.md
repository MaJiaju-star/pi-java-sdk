# 包结构

SDK 按职责拆分 Java 包，不在 `works.earendil.pi` 根包堆放公开类。每个包通过 `package-info.java` 说明职责。

## 包一览

| 包 | 职责 | 主要类型 |
| --- | --- | --- |
| `works.earendil.pi.client` | 客户端入口和 JSONL 读写 | `PiClient`（公开）、`StrictJsonlReader`（包私有） |
| `works.earendil.pi.config` | 子进程、超时和反压配置 | `PiClientConfig`、`PiEventOverflowStrategy` |
| `works.earendil.pi.conversation` | 对话输入和值对象 | `PiImage`、`ThinkingLevel`、`QueueMode`、`PiStreamingBehavior` |
| `works.earendil.pi.event` | 原始事件、强类型事件和订阅 | `PiEvent`、`PiTypedEvent`、`PiEventType`、`PiSubscription`、`PiEventDecoder`（包私有） |
| `works.earendil.pi.extension` | Extension UI 请求和回复 | `PiExtensionUiRequest`、`PiExtensionUiResponse` |
| `works.earendil.pi.rpc` | RPC 命令、响应和数据结构 | `PiRpcCommand`、`PiResponse`、`PiRpcTypes`、`PiRun` |
| `works.earendil.pi.process` | CLI 版本与进程退出信息 | `PiCliVersion`、`PiProcessExit` |
| `works.earendil.pi.pool` | 多会话进程池 | `PiClientPool`、`PiClientFactory` |
| `works.earendil.pi.session` | 历史会话文件的本地只读访问 | `SessionLister` |
| `works.earendil.pi.exception` | SDK 异常层次 | `PiClientException` 及 4 个子类 |

## 公开类型说明

### `client` 包

- `PiClient`：唯一客户端入口，线程安全，`AutoCloseable`。一个实例对应一个 `pi --mode rpc` 子进程和一个活动会话。
- `StrictJsonlReader`：stdout JSONL 解析器，负责严格 UTF-8 校验、大小限制和逐行 JSON 解析，包私有。

### `event` 包

- `PiEvent`：`record (String type, JsonNode raw)`，原始事件。
- `PiEventType`：已知事件类型枚举，`fromWireValue` 未知时返回 `UNKNOWN`。
- `PiTypedEvent`：sealed interface，20 个 record 视图覆盖全部已知事件。
- `PiSubscription`：`AutoCloseable`，`close()` 取消订阅。
- `PiEventDecoder`：把 `PiEvent` 解码为 `PiTypedEvent`，包私有。

### `rpc` 包

- `PiRpcCommand`：33 个命令的枚举，`wireValue()` 为协议字符串。
- `PiResponse`：`record (id, command, data, raw)`，`dataAs()` 转换数据。
- `PiRun`：`record (accepted, settled)`，prompt 的两阶段完成句柄。
- `PiRpcTypes`：全部响应数据 record（`Model`、`SessionState`、`Usage`、`BashResult`、`CompactionResult`、`SessionStats`、`SessionTree` 等），开放字段保留 `JsonNode`。

### `conversation` 包

- `PiImage`：`record (data, mimeType)`，`fromPath` / `fromBytes` 构造。
- `ThinkingLevel`：7 档思考等级，`@JsonValue`/`@JsonCreator` 序列化。
- `QueueMode`：`ALL` / `ONE_AT_A_TIME`，`@JsonValue`/`@JsonCreator` 序列化。
- `PiStreamingBehavior`：`STEER` / `FOLLOW_UP`。

### `exception` 包

```
PiClientException（基类，RuntimeException）
├─ PiRpcException
├─ PiRequestTimeoutException
├─ PiProcessException
└─ PiProtocolException
```

详见 [12-错误处理安全与反压](12-错误处理安全与反压.md)。

### `pool` 包

- `PiClientPool`：多会话进程池，`AutoCloseable`，`create()` / `getOrRecover()` / `recover()` / `remove()`。
- `PiClientFactory`：函数式接口 `PiClient start() throws IOException`。
- `Entry`：`record (id, client)`。

### `session` 包

- `SessionLister`：历史会话文件的本地只读工具，`list()` / `list(sessionDir)` / `list(sessionDir, cwd)` / `peek(file)`，不启动 PI 子进程。
- `SessionFile`：`record (file, lastModified, sizeBytes)`。
- `SessionSummary`：`record (sessionId, version, cwd, timestamp, entryCount, messageCount, lastText)`。

### `process` 包

- `PiCliVersion`：`record (raw, major, minor, patch)`，`detect()` / `semanticVersion()` / `isTestedVersion()`。
- `PiProcessExit`：`record (exitCode, expected, stderr)`。

## 最常用 import

```java
import works.earendil.pi.client.PiClient;
import works.earendil.pi.config.PiClientConfig;
import works.earendil.pi.event.PiTypedEvent;
import works.earendil.pi.rpc.PiRun;
import works.earendil.pi.rpc.PiRpcTypes;
```

## 可见性约定

- 公开 API 只在 `client`、`config`、`conversation`、`event`、`extension`、`rpc`、`process`、`pool`、`exception` 九个包中。
- `StrictJsonlReader`、`PiEventDecoder` 与各自实现放在同一包，保持包级可见，不作为公共 API。
- 数据 record 统一用 `@JsonIgnoreProperties(ignoreUnknown = true)` 标注，升级 PI 后新增字段不会导致反序列化失败。
