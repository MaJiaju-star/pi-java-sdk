# 流式事件

PI 在 stdout 上推送 JSONL 事件。SDK 提供三层访问：原始 `PiEvent`、便捷方法 `textDelta()`、强类型 `PiTypedEvent`。

## 原始事件

```java
PiSubscription subscription = client.subscribe(event -> {
    event.textDelta().ifPresent(System.out::print);
    archive(event.raw());
});
```

- `PiEvent` 是 `record (String type, JsonNode raw)`，`type` 为协议类型，`raw` 保留完整 JSON，确保新 PI 版本增加字段或事件时仍可访问。
- `event.is("message_update")` 可做字符串类型判断。
- `event.textDelta()` 只在 `message_update` 且 `assistantMessageEvent.type == "text_delta"` 时返回增量文本。

## 强类型事件

```java
client.subscribe(event -> {
    PiTypedEvent typed = event.typed(client.objectMapper());
    switch (typed) {
        case PiTypedEvent.MessageUpdate update -> {
            if ("text_delta".equals(update.assistantMessageEvent().type())) {
                System.out.print(update.assistantMessageEvent().delta());
            }
        }
        case PiTypedEvent.ToolExecution tool ->
                System.out.println(tool.type() + ": " + tool.toolName());
        case PiTypedEvent.Compaction compaction ->
                System.out.println("压缩原因: " + compaction.reason());
        case PiTypedEvent.Unknown unknown ->
                System.out.println("未知事件: " + unknown.wireType());
        default -> { }
    }
});
```

`PiTypedEvent` 是 sealed interface，用 switch 模式匹配（JDK 21+）穷尽各视图。未知事件映射为 `Unknown`。

> 需要更扁平、语义化的事件模型（每个语义事件一个 record，便于业务处理和转发前端）时，可用 `works.earendil.pi.sse.SseEvent`，两者选型对比见 [18-SSE事件桥接](18-SSE事件桥接.md)。

## 强类型视图字段

| 视图 | 对应事件 | 字段 |
| --- | --- | --- |
| `Marker` | `agent_start`、`agent_settled`、`turn_start`、`summarization_retry_finished` | `type`、`raw` |
| `AgentEnd` | `agent_end` | `messages`、`willRetry`、`raw` |
| `TurnEnd` | `turn_end` | `message`、`toolResults`、`raw` |
| `MessageLifecycle` | `message_start`、`message_end` | `type`、`message`、`raw` |
| `MessageUpdate` | `message_update` | `usage`、`assistantMessageEvent`、`raw` |
| `ToolExecution` | `tool_execution_start/update/end` | `type`、`toolCallId`、`toolName`、`args`、`partialResult`、`result`、`error`、`raw` |
| `QueueUpdate` | `queue_update` | `steering`、`followUp`、`raw` |
| `Compaction` | `compaction_start`、`compaction_end` | `type`、`reason`、`result`、`aborted`、`willRetry`、`errorMessage`、`raw` |
| `Retry` | `auto_retry_start`、`auto_retry_end`、`summarization_retry_scheduled` | `type`、`attempt`、`maxAttempts`、`delayMillis`、`errorMessage`、`success`、`finalError`、`raw` |
| `SummarizationRetry` | `summarization_retry_attempt_start` | `type`、`source`、`reason`、`raw` |
| `BashUpdate` | `bash_execution_update` | `requestId`、`delta`、`raw` |
| `EntryAppended` | `entry_appended` | `entry`、`raw` |
| `SessionInfoChanged` | `session_info_changed` | `name`、`raw` |
| `ThinkingLevelChanged` | `thinking_level_changed` | `level`、`raw` |
| `ExtensionError` | `extension_error` | `extensionPath`、`event`、`error`、`raw` |
| `ExtensionUi` | `extension_ui_request` | `request`、`raw` |
| `Unknown` | 未知类型 | `wireType`、`raw` |

所有视图都保留 `raw`，升级后新增字段仍可读取。

## `message_update` 的增量子类型

`MessageUpdate.assistantMessageEvent()` 的 `type` 字段有 12 种取值：

| 子类型 | 关键字段 | 含义 |
| --- | --- | --- |
| `start` | `partial` | 助手消息开始 |
| `text_start` | `contentIndex`、`partial` | 文本块开始 |
| `text_delta` | `contentIndex`、`delta` | 文本增量（实时正文） |
| `text_end` | `contentIndex`、`content` | 文本块结束 |
| `thinking_start` | `contentIndex` | 思考块开始 |
| `thinking_delta` | `contentIndex`、`delta` | 思考增量 |
| `thinking_end` | `contentIndex`、`content` | 思考块结束 |
| `toolcall_start` | `contentIndex` | 工具调用参数开始 |
| `toolcall_delta` | `contentIndex`、`delta` | 工具调用参数增量 |
| `toolcall_end` | `contentIndex`、`toolCall` | 工具调用参数完成 |
| `done` | `reason`、`message` | 助手消息完成（`stop`/`length`/`toolUse`/`deferred`） |
| `error` | `reason`、`error` | 助手消息出错（`aborted`/`error`） |

`AssistantMessageEvent` record 的字段为 `type`、`contentIndex`、`delta`、`content`、`id`、`toolName`、`toolCall`，不同子类型只填充相关字段。

## 事件类别

| 类别 | 事件 |
| --- | --- |
| Agent | `agent_start`、`agent_end`、`agent_settled` |
| Turn | `turn_start`、`turn_end` |
| 消息 | `message_start`、`message_update`、`message_end` |
| 工具 | `tool_execution_start`、`tool_execution_update`、`tool_execution_end` |
| 队列 | `queue_update` |
| 压缩 | `compaction_start`、`compaction_end` |
| 重试 | `auto_retry_start`、`auto_retry_end`、`summarization_retry_scheduled`、`summarization_retry_attempt_start`、`summarization_retry_finished` |
| 会话 | `entry_appended`、`session_info_changed`、`thinking_level_changed` |
| Bash | `bash_execution_update` |
| 扩展 | `extension_ui_request`、`extension_error` |

> `message_update` 只包含增量，不包含累计消息。实时界面应累加 `delta`，并把 `message_end.message` 当作最终权威消息；`agent_settled` 表示重试、压缩和后续队列均已结束。

## 取消订阅

```java
subscription.close();
```

`PiSubscription` 实现 `AutoCloseable`。监听器异常交给 `listenerErrorHandler`（默认打印堆栈），不会终止协议读取。

> 需要把事件桥接到 Web 端的 Server-Sent Events 时，见 [18-SSE事件桥接](18-SSE事件桥接.md)：该模块把本页事件规范化为扁平实体并转发为 SSE 帧。
