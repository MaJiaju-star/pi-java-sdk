# 会话与持久化

## 列出历史会话

JSONL RPC 协议没有「列出历史会话」命令，因此枚举历史会话需要用 `SessionLister`（本地文件操作，不启动 PI 子进程）：

```java
import works.earendil.pi.session.SessionLister;

// 默认目录 ~/.pi/agent/sessions 下的全部会话（按 mtime 倒序）
for (SessionLister.SessionFile f : SessionLister.list()) {
    System.out.println(f.file());
}

// 指定工作目录的会话
for (SessionLister.SessionFile f : SessionLister.list(
        SessionLister.defaultSessionDir(), Path.of("D:/code/PI"))) {
    System.out.println(f.file());
}

// 读头部与统计（不启动 PI）
SessionLister.SessionSummary s = SessionLister.peek(sessionFile);
System.out.println(s.sessionId());
System.out.println(s.cwd());
System.out.println(s.messageCount());
System.out.println(s.lastText());
```

会话默认存放于 `~/.pi/agent/sessions/--<cwd编码>--/<时间戳>_<uuid>.jsonl`，目录编码规则为路径分隔符与冒号替换为 `-`、前后加 `--`。设置 `PI_CODING_AGENT_DIR` 环境变量时改用该目录下的 `sessions` 子目录。

拿到会话文件路径后，用 `switchSession()` 加载，再读取内容（见下文）。

## 新建和切换

```java
PiRpcTypes.Cancelled created = client.newSession().join();
PiRpcTypes.Cancelled child = client.newSession("parent-session-file").join();
PiRpcTypes.Cancelled switched = client.switchSession("D:/sessions/session.jsonl").join();
```

- `newSession()` 创建并切换到新会话；`newSession(parentSession)` 创建指定父会话的子会话。
- `switchSession(sessionPath)` 切换到已有会话文件。
- 返回 `Cancelled`（含 `cancelled` 布尔），因为扩展钩子可以取消会话操作；`cancelled=true` 表示切换前的运行被取消。
- `sessionFile` 由配置的 `sessionDirectory` 或 PI 默认会话目录决定。

## 会话名称和统计

```java
client.setSessionName("支付模块重构").join();
PiRpcTypes.SessionStats stats = client.getSessionStats().join();
```

`SessionStats` 字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `sessionFile` | `String` | 会话文件路径 |
| `sessionId` | `String` | 会话 ID |
| `userMessages` | `int` | 用户消息数 |
| `assistantMessages` | `int` | 助手消息数 |
| `toolCalls` | `int` | 工具调用数 |
| `toolResults` | `int` | 工具结果数 |
| `totalMessages` | `int` | 消息总数 |
| `tokens` | `TokenStats` | token 统计（`input`/`output`/`cacheRead`/`cacheWrite`/`total`） |
| `cost` | `double` | 总费用 |
| `contextUsage` | `JsonNode` | 上下文用量详情（开放结构） |

## 当前会话状态

```java
PiRpcTypes.SessionState state = client.getState().join();
```

`SessionState` 的 12 个字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `model` | `Model` | 当前模型 |
| `thinkingLevel` | `ThinkingLevel` | 当前思考等级 |
| `isStreaming` | `boolean` | 是否正在生成 |
| `isCompacting` | `boolean` | 是否正在压缩上下文 |
| `steeringMode` | `QueueMode` | steering 队列模式 |
| `followUpMode` | `QueueMode` | follow-up 队列模式 |
| `sessionFile` | `String` | 会话文件路径 |
| `sessionId` | `String` | 会话 ID |
| `sessionName` | `String` | 会话名称 |
| `autoCompactionEnabled` | `boolean` | 是否启用自动压缩 |
| `messageCount` | `int` | 已持久化消息数 |
| `pendingMessageCount` | `int` | 等待处理的消息数 |

## 分支与克隆

```java
List<PiRpcTypes.ForkMessage> candidates = client.getForkMessages().join();
PiRpcTypes.ForkResult forked = client.fork(candidates.getFirst().entryId()).join();
PiRpcTypes.Cancelled cloned = client.cloneSession().join();
```

- `getForkMessages()` 返回 `List<ForkMessage>`，每个 `ForkMessage` 含 `entryId`（会话条目 ID）和 `text`（消息文本）。
- `fork(entryId)` 从指定条目创建分支，返回 `ForkResult`（含 `text` 和 `cancelled`）。
- `cloneSession()` 克隆当前会话（在当前叶条目处 fork），返回 `Cancelled`。

## 条目和树

```java
PiRpcTypes.Entries all = client.getEntries().join();
PiRpcTypes.Entries incremental = client.getEntries(lastEntryId).join();
PiRpcTypes.SessionTree tree = client.getTree().join();
List<JsonNode> messages = client.getMessages().join();
String lastText = client.getLastAssistantText().join();
```

- `getEntries()` 返回全部会话条目；`getEntries(since)` 返回指定条目之后的增量（`since` 不存在时 PI 报错）。
- `Entries` 含 `entries`（`List<JsonNode>`）和 `leafId`（当前叶条目 ID）。
- `getTree()` 返回 `SessionTree`（含 `tree` 和 `leafId`）；`SessionTreeNode` 含 `entry`、`children`、`label`、`labelTimestamp`。
- `getMessages()` 返回 `List<JsonNode>`，`getLastAssistantText()` 返回 `String`（无助手消息时为 `null`）。

消息、会话条目和工具结果允许扩展自定义内容，因此 SDK 对这些开放联合类型保留 `JsonNode`，避免丢弃未知字段。

## 会话事件

会话变化通过流式事件报告：`entry_appended`（新条目）、`session_info_changed`（名称变更）、`thinking_level_changed`（思考等级变更）。见 [04-流式事件](04-流式事件.md)。

## 导出 HTML

```java
PiRpcTypes.PathResult result = client.exportHtml("D:/reports/session.html").join();
System.out.println(result.path());
```

未指定路径时使用 PI 的默认导出路径：

```java
client.exportHtml().join();
```

`PathResult` 含生成文件的 `path`。
