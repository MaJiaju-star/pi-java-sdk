# 会话与持久化

## 新建和切换

```java
PiRpcTypes.Cancelled created = client.newSession().join();
PiRpcTypes.Cancelled child = client.newSession("parent-session-file").join();
PiRpcTypes.Cancelled switched = client.switchSession("D:/sessions/session.jsonl").join();
```

返回值包含 `cancelled`，因为扩展钩子可以取消会话操作。

## 会话名称和统计

```java
client.setSessionName("支付模块重构").join();
PiRpcTypes.SessionStats stats = client.getSessionStats().join();
System.out.println(stats.tokens().total());
System.out.println(stats.cost());
```

## 分支与克隆

```java
List<PiRpcTypes.ForkMessage> candidates = client.getForkMessages().join();
PiRpcTypes.ForkResult forked = client.fork(candidates.getFirst().entryId()).join();
PiRpcTypes.Cancelled cloned = client.cloneSession().join();
```

## 条目和树

```java
PiRpcTypes.Entries all = client.getEntries().join();
PiRpcTypes.Entries incremental = client.getEntries(lastEntryId).join();
PiRpcTypes.SessionTree tree = client.getTree().join();
List<JsonNode> messages = client.getMessages().join();
String lastText = client.getLastAssistantText().join();
```

消息、会话条目和工具结果允许扩展自定义内容，因此 SDK 对这些开放联合类型保留 `JsonNode`，避免丢弃未知字段。

## 导出 HTML

```java
PiRpcTypes.PathResult result = client.exportHtml("D:/reports/session.html").join();
```

未指定路径时使用 PI 的默认导出路径：

```java
client.exportHtml().join();
```
