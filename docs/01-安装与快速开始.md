# 安装与快速开始

## 环境要求

- JDK 25，本工程使用环境变量 `JAVA_HOME` 中的 JDK。
- Maven 3.9 或更高版本。
- 已安装 PI CLI，且 `pi` 或 Windows 下的 `pi.cmd` 可执行。
- PI 已配置可用模型和凭据。

确认环境：

```powershell
java -version
mvn -version
pi --version
```

## 构建

在 `pi-java-sdk` 仓库根目录执行：

```powershell
$env:MAVEN_OPTS='-Xms32m -Xmx256m -XX:+UseSerialGC -Dfile.encoding=UTF-8'
mvn clean verify
```

- `mvn clean verify`：编译 + 测试 + 打包。
- `mvn test`：只编译并跑测试（测试用 `FakePiProcess` 模拟子进程，不依赖真实 PI CLI）。
- 测试中的 `PiRpcCommandCoverageTest` 是协议漂移检查：当本地存在 PI 源码时，会比较 Java 命令枚举与 TypeScript 协议定义（见 [17-对齐审计](17-对齐审计.md)）。

## 生成本地 Javadoc

```powershell
mvn javadoc:javadoc
```

公开 API 使用中文 Javadoc，构建要求通过 `javadoc -Werror -Xdoclint:all`（见 [15-Javadoc与API注释](15-Javadoc与API注释.md)）。

## 安装到本地仓库

当前模块尚未发布到 Maven Central。在本机业务工程引用前先执行：

```powershell
mvn install
```

然后加入依赖：

```xml
<dependency>
    <groupId>works.earendil.pi</groupId>
    <artifactId>pi-java-sdk</artifactId>
    <version>0.1.1</version>
</dependency>
```

## 最小示例

```java
import java.nio.file.Path;
import works.earendil.pi.client.PiClient;
import works.earendil.pi.config.PiClientConfig;
import works.earendil.pi.rpc.PiRun;

PiClientConfig config = PiClientConfig.builder()
        .workingDirectory(Path.of("D:/workspace/my-project"))
        .noSession(true)
        .build();

try (PiClient client = PiClient.start(config)) {
    client.subscribe(event -> event.textDelta().ifPresent(System.out::print));
    PiRun run = client.prompt("说明这个项目的目录结构");
    run.accepted().join();
    run.settled().join();
}
```

`accepted()` 只表示命令已接收。完整运行结束必须等待 `settled()`（见 [03-对话与图片](03-对话与图片.md)）。

## 从源码运行 PI

如果没有全局安装 PI，可以传入完整命令前缀：

```java
PiClientConfig config = PiClientConfig.builder()
        .command(List.of(
                "node",
                "D:/code/pi-main/pi-main/packages/coding-agent/dist/bundle/cli.js"
        ))
        .workingDirectory(Path.of("D:/my-project"))
        .build();
```

`command(...)` 后不需要写 `--mode rpc`，SDK 会自动追加。
