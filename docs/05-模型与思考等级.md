# 模型与思考等级

## 查询模型

```java
List<PiRpcTypes.Model> models = client.getAvailableModels().join();
for (PiRpcTypes.Model model : models) {
    System.out.printf("%s/%s context=%d maxTokens=%d%n",
            model.provider(), model.id(), model.contextWindow(), model.maxTokens());
}
```

## `PiRpcTypes.Model` 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | `String` | 模型 ID |
| `name` | `String` | 显示名称 |
| `api` | `String` | API 类型（如 `anthropic`、`openai-completions`） |
| `provider` | `String` | 提供商名称 |
| `baseUrl` | `String` | API 基础地址 |
| `reasoning` | `boolean` | 是否支持推理 |
| `thinkingLevelMap` | `Map<String,String>` | 统一思考等级到提供商值的映射 |
| `input` | `List<String>` | 支持的输入类型（如 `text`、`image`） |
| `cost` | `ModelCost` | 单价信息 |
| `contextWindow` | `long` | 上下文窗口 token 数 |
| `maxTokens` | `long` | 最大输出 token 数 |
| `samplingParams` | `JsonNode` | 采样参数（开放结构） |
| `headers` | `Map<String,String>` | 附加请求头 |
| `compat` | `JsonNode` | 提供商兼容配置（开放结构） |

`ModelCost` 含 `input`、`output`、`cacheRead`、`cacheWrite` 单价和 `tiers`（阶梯定价）。`ModelCostTier` 除四项单价外还有 `inputTokensAbove`，表示超过该输入 token 下限后生效。

可扩展字段（`samplingParams`、`compat`）使用 `JsonNode` 保留，避免升级丢字段。

## 切换模型

```java
PiRpcTypes.Model selected = client.setModel("openai", "gpt-5.4").join();
PiRpcTypes.ModelCycle next = client.cycleModel().join();
```

- `setModel(provider, modelId)` 返回切换后的 `Model`；若 PI 找不到模型，返回 `success:false`，Java 侧抛出 `PiRpcException`。
- `cycleModel()` 返回 `ModelCycle`（含 `model`、`thinkingLevel`、`isScoped`），没有可循环模型时返回 `null`。
- `isScoped` 表示切换结果是否受当前模型范围（scoped models）限制。

## 思考等级

```java
List<ThinkingLevel> levels = client.getAvailableThinkingLevels().join();
client.setThinkingLevel(ThinkingLevel.HIGH).join();
PiRpcTypes.ThinkingLevelCycle next = client.cycleThinkingLevel().join();
```

`ThinkingLevel` 枚举共七档：

| 枚举 | 协议值 | 说明 |
| --- | --- | --- |
| `OFF` | `off` | 不使用推理预算 |
| `MINIMAL` | `minimal` | 使用最小推理预算 |
| `LOW` | `low` | 使用低推理预算 |
| `MEDIUM` | `medium` | 使用中等推理预算 |
| `HIGH` | `high` | 使用高推理预算 |
| `XHIGH` | `xhigh` | 使用超高推理预算 |
| `MAX` | `max` | 使用模型允许的最大推理预算 |

- 具体模型可能只支持其中一部分，应以 `getAvailableThinkingLevels()` 的查询结果为准。
- `cycleThinkingLevel()` 返回 `ThinkingLevelCycle`（含 `level`），无可切换等级时返回 `null`。
- `ThinkingLevel` 与 `QueueMode` 都用 `@JsonValue`/`@JsonCreator` 标注 `wireValue()`/`fromWireValue()`，序列化时使用协议字符串。

## Token 用量与费用

```java
PiRpcTypes.Usage usage = event.typed(client.objectMapper()) instanceof PiTypedEvent.MessageUpdate u
        ? u.usage() : null;
```

`Usage` 含 `input`、`output`、`cacheRead`、`cacheWrite`、`totalTokens` 和 `UsageCost cost`。`UsageCost` 含五项费用明细（`input`、`output`、`cacheRead`、`cacheWrite`、`total`）。

## 当前状态

```java
PiRpcTypes.SessionState state = client.getState().join();
System.out.println(state.model());
System.out.println(state.thinkingLevel());
System.out.println(state.isStreaming());
System.out.println(state.sessionId());
```

`SessionState` 的完整 12 字段见 [07-会话与持久化](07-会话与持久化.md)，此处常用的还有 `isCompacting`、`steeringMode`、`followUpMode`、`autoCompactionEnabled`、`messageCount`、`pendingMessageCount`。
